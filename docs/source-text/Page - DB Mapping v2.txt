Page to Database Mapping

This document provides a Page-to-Database Mapping for the DEZOLVER platform.
It covers all pages and screens defined in the Figma design and maps each page to
the corresponding database tables/entities required to support its functionality.
The mapping is organized by stakeholder — Super Admin, Finance Team, HOD,
Manager, and Student — making it easier for developers to understand which
database entities are associated with each UI page and maintain consistency
between the frontend design and database architecture.
